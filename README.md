# Zen Redesign Test

Неофициальный концепт мобильного интерфейса Дзена, подготовленный в рамках тестового задания. В этой версии прототип развивает главную ленту, добавляет блок коротких вертикальных видео, компактные новости с миниатюрами и отдельную «Студию автора».

> Это демонстрационный frontend-прототип, не связанный с командой или владельцами сервиса Дзен. Данные статистики, публикации и реакции в интерфейсе условные.

## Что реализовано

- Адаптивная мобильная оболочка и нижняя навигация.
- Верхний блок «Короткие видео» с горизонтальной прокруткой и сценарием открытия ролика.
- Блок «Коротко о главном» с миниатюрами, источниками и временем публикации.
- Основная лента, тематические категории, поиск, уведомления, лайки, закладки и подписки.
- «Студия автора»: обзор канала, демонстрационные показатели, публикации и переходы к созданию контента, управлению материалами, аналитике и настройкам.
- Демонстрационные формы создания и редактирования публикации.

## Продуктовая гипотеза

Концепт проверяет три направления улучшения:

1. Более заметное размещение коротких видео может повысить долю пользователей, начинающих просмотр.
2. Единая студия автора может упростить управление каналом и повысить долю успешно завершённых сценариев публикации.
3. Миниатюры в компактных новостных карточках могут повысить заметность материалов и CTR.

Подробное обоснование, метрики и план проверки находятся в [`docs/PRODUCT_PROPOSAL.md`](docs/PRODUCT_PROPOSAL.md).

## Технологии

- HTML5
- CSS3
- Vanilla JavaScript (ES Modules)
- Font Awesome 6 (CDN)
- GitHub Pages (статический хостинг)

Сборщик, backend и npm-зависимости не требуются.

## Запуск локально

```bash
git clone https://github.com/MaxGog/zen-redesign-test.git
cd zen-redesign-test
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Также можно использовать расширение Live Server в VS Code. Не запускайте проект через `file://`: браузер может ограничивать ES Modules.

## Публикация на GitHub Pages

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Укажите `main` и каталог `/ (root)`.
4. Сохраните настройки.

## Ограничения прототипа

- Backend, авторизация, база данных и API отсутствуют.
- Видео не воспроизводится: экран просмотра иллюстрирует целевой сценарий и требует подключения видеоплеера и источника контента.
- Новости, статистика, подписчики и публикации — демонстрационные данные.
- Формы и действия показывают интерфейсные состояния, но не сохраняют данные на сервере.
- Метрики перечислены как показатели для будущего эксперимента; фактических результатов A/B-тестирования нет.
- Изображения и иконки загружаются со сторонних ресурсов, поэтому для их отображения нужен интернет.
