# Редизайн главного экрана Дзен (Тестовое задание)

Этот репозиторий содержит базовый прототип главного экрана мобильного приложения Дзен, воссозданный с помощью HTML, Tailwind CSS и FontAwesome.

## 🎯 Цель проекта

Воссоздать текущий интерфейс приложения для дальнейшего предложения редизайна (улучшения пользовательского опыта и продуктовых метрик).

## 🛠 Стек технологий

* HTML5 (Семантическая верстка)
* Tailwind CSS (Стилизация через CDN)
* FontAwesome (Иконки)
* Адаптивная верстка (Mobile-first, на десктопе отображается в рамке телефона)
