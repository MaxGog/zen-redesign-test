# Zen Redesign Test

Концепт мобильного интерфейса **Дзена**, созданный в рамках тестового задания. Проект демонстрирует адаптивную вёрстку главной ленты, навигацию и базовые интерактивные состояния на чистых HTML, CSS и JavaScript.

> **Статус:** демонстрационный проект. Это неофициальная концепция редизайна, не связанная с командой или владельцами сервиса Дзен.

## Возможности

- Адаптивная оболочка мобильного приложения.
- Главная лента с карточками публикаций разных типов.
- Переключение тематических категорий.
- Нижняя панель навигации.
- Меню профиля, панели поиска и уведомлений.
- Демонстрационные действия: лайки, закладки и подписки.
- Поддержка системного safe area на мобильных устройствах.

Функции, связанные с аккаунтом и публикацией контента, представлены интерфейсными заглушками.

## Технологии

- **HTML5** — семантическая структура страниц.
- **CSS3** — адаптивная компоновка и визуальные состояния.
- **Vanilla JavaScript (ES Modules)** — интерактивность без frontend-фреймворков.
- **Font Awesome** — иконки через CDN.
- **GitHub Pages** — статический хостинг.

Сборщик, backend и установка npm-зависимостей для текущей версии не требуются.

## Запуск локально

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/MaxGog/zen-redesign-test.git
   cd zen-redesign-test
   ```

2. Запустите проект через любой локальный статический сервер.

   Например, в Visual Studio Code можно использовать расширение **Live Server**.

   Либо, если установлен Python:

   ```bash
   python3 -m http.server 8000
   ```

3. Откройте в браузере `http://localhost:8000`.

> Не рекомендуется запускать проект двойным щелчком по `index.html`: браузер может ограничивать загрузку JavaScript ES Modules через `file://`.

## Публикация на GitHub Pages

Проект совместим с GitHub Pages и не требует этапа сборки.

1. Откройте **Settings → Pages** в настройках репозитория.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Укажите ветку `main` и каталог `/ (root)`.
4. Сохраните настройки.

После публикации GitHub Pages будет обновлять сайт при изменениях в выбранной ветке.

Адрес опубликованной страницы обычно имеет вид:

`https://maxgog.github.io/zen-redesign-test/`

Если репозиторий или настройки Pages изменятся, фактический адрес может отличаться.

## Ограничения

- Это статический frontend-прототип: серверная часть и база данных отсутствуют.
- Состояния лайков, подписок и закладок не синхронизируются между устройствами и не сохраняются как пользовательские данные.
- Поиск работает только по тексту публикаций, уже присутствующих в DOM.
- Изображения и иконки загружаются со сторонних ресурсов; для их отображения требуется интернет-соединение.
- Внешний вид и поведение могут отличаться от официального приложения Дзена.
