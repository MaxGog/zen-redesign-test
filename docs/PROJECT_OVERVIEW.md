# Обзор проекта

## Назначение

Zen Redesign Test — статический frontend-прототип мобильного интерфейса Дзена. Его задача — показать подход к построению адаптивного интерфейса и реализации базовых пользовательских сценариев без backend и frontend-фреймворков.

## Архитектура

Проект намеренно оставлен компактным:

- `index.html` содержит разметку экранов и компонентов.
- `css/style.css` содержит общие токены дизайна, layout, компоненты и состояния.
- `js/app.js` отвечает за обработчики событий, переключение категорий, панели, поиск и демонстрационные действия.

Такое разделение выбрано для небольшого тестового проекта: оно сохраняет понятные границы ответственности и не создаёт лишней структуры из множества мелких файлов.

## Основные сценарии

1. Пользователь просматривает ленту публикаций.
2. Переключает тематические категории.
3. Открывает поиск и фильтрует уже загруженные карточки по тексту.
4. Открывает меню профиля, уведомления и демонстрационные разделы.
5. Использует действия лайка, закладки и подписки.

## Принципы реализации

- Семантические HTML-элементы там, где это уместно.
- Адаптивная компоновка с приоритетом мобильного экрана.
- Небольшое количество зависимостей.
- Отсутствие сборочного этапа.
- Разделение структуры, оформления и поведения.

## Дальнейшее развитие

При расширении проекта можно вынести отдельные крупные компоненты в самостоятельные CSS- и JS-модули. Для текущего объёма это намеренно не делается, чтобы не усложнять навигацию по коду и ускорить работу над главным экраном.
