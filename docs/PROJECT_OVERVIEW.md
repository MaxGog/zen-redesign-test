# Обзор проекта

## Назначение

Zen Redesign Test — статический frontend-прототип мобильного интерфейса Дзена. Он демонстрирует три продуктовые доработки: короткие вертикальные видео в верхней части главной, компактные новости с миниатюрами и отдельную студию автора.

## Архитектура

Проект намеренно оставлен компактным:

- `index.html` — структура экранов и компонентов.
- `css/style.css` — дизайн-токены, компоновка, компоненты и состояния.
- `js/app.js` — обработчики событий, фильтрация, поиск, панели и демонстрационные сценарии.
- `docs/PRODUCT_PROPOSAL.md` — проблема, гипотезы, решения, метрики и план проверки.

Такое разделение подходит для небольшого тестового проекта и не создаёт лишней структуры.

## Основные пользовательские сценарии

1. Просмотр коротких видео из блока в верхней части главной.
2. Открытие новости из компактного списка с миниатюрами.
3. Просмотр основной ленты и переключение категорий.
4. Открытие студии автора и просмотр демонстрационной статистики.
5. Переход к управлению контентом, созданию публикации, аналитике и настройкам канала.
6. Поиск, уведомления, лайки, закладки и подписки.

## Принципы реализации

- Mobile-first и адаптивная компоновка.
- HTML, CSS и Vanilla JavaScript без сборщика.
- Повторное использование существующей оболочки и визуального языка.
- Понятные интерфейсные состояния и короткие пользовательские сценарии.
- Явное обозначение демонстрационных данных и ограничений.

## Ограничения

Backend и интеграции отсутствуют. Данные не сохраняются между сессиями. Экран видео демонстрирует сценарий, но не воспроизводит реальный ролик. Аналитические показатели условные и не отражают реальные данные Дзена.
